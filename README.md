# Feed Dry Matter Conversion Tutor — v2

The practice generator now uses different illustrative feed types and different values each time.

Practice cases can include:
- crude protein;
- fat;
- fibre;
- Omega-6.

The same dry-matter conversion is used for any constituent expressed as an as-fed percentage:

`Nutrient % DM = nutrient % as-fed × 100 / DM %`

The generated feed names and values are illustrative teaching examples, not reference feed-composition values.

Only `index.html` is needed for GitHub Pages.
