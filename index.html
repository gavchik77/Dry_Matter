Key formulas

DM % = 100 − Moisture %
Nutrient % on DM basis = As-fed nutrient % × 100 ÷ DM %
As-fed nutrient % = DM-basis nutrient % × DM % ÷ 100

Dry-matter conversion does not create nutrient. It removes water from the denominator so feeds with different moisture contents can be compared. The same calculation can be used for any constituent expressed as an as-fed percentage — for example crude protein, fat, fibre, ash, minerals or Omega-6.

1. Find the dry matter

Dry food: 30% protein, 10% moisture. Canned food: 9% protein, 78% moisture.

Use 100 − moisture %.

2. Convert protein to a DM basis

Convert both before comparing.

3. Recalculate the full poultry-feed label

Premium Poultry Mixed Corn: moisture 22%, CP 13.5%, oil/fat 3.4%, fibre 2.3%, ash 2.0%, sodium 0.01%.

First find DM = 100 − 22, then use the same DM denominator for every constituent.

4. Reverse the calculation

A feed is 40% crude protein on a DM basis and 90% DM. What is crude protein as-fed?

Use DM-basis nutrient % × DM % ÷ 100.
